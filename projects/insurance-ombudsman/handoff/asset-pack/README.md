# Episode 02 production assets

Open **START_HERE.html** after extracting this folder. Read **CLAUDE_VISUAL_HANDOFF.md**, then **SCRIPT_CORRECTIONS.md**.

- `footage/`: 20 downloaded real stock footage clips.
- `graphics/`: eight editable SVG graphics and matching 4K PNGs.
- `previews/`: contact sheet and three sampled frames per clip.
- `official_sources/`: primary documents, source snapshots, reference images and CIO registration tutorial.
- `FOOTAGE_REGISTER.csv`: clip-to-scene mapping, source/licence links, technical specifications and limitations.
- `footage_manifest.json`: machine-readable source and media metadata.

This is an asset pack, not a completed eleven-minute film. No voiceover, final edit, real complaint or authenticated portal walkthrough was created.

Stock people/scenes are illustrative. Source resolutions vary; see the register. The CIO tutorial is reference material, not cleared stock. The eight graphics are supplied for animation; do not treat the static PNG layouts as the whole visual treatment.
