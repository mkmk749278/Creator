# D5_engines_jets: 14 of 99 engines, 29 jets

Session D scene for *The Jet Engine Paradox* (program 102.94–112.64, 9.7 s, 1920×1080, 30 fps).
Spec: `projects/jet-engine-paradox/scenes.md`. Drive: https://drive.google.com/file/d/1ebURix7x5AEyAVROpIqzzuJy1-xRfBul/view · contact sheet: https://drive.google.com/file/d/1X4rKmtjgwxb_r4rvLEz06897uNI077iX/view
