# whiteboard

Real marker handwriting on a whiteboard, for any explainer: every letter is **written stroke by stroke** (the ink grows
along each pen stroke, the marker's nib rides the exact point, the pen lifts and travels between strokes), plus
hand-drawn underlines, circles, arrows, boxes, ticks, crosses, strike-throughs, hatched bars and a duster wipe. Built for
*Minimum Amount Due* (owner, 2026-10-11: "proper whiteboard, reusable, write what we want in future videos").

## Use it in a film
1. `cp -r video/lib/whiteboard video/<film>/<shot>` (or copy `index.html` only) and write that folder's `params.js`.
2. `npm run vendor` (copies GSAP, Inter and `vendor/wb/` = `wb.js`, `wb-fonts.js`, `wb.css` into the folder).
3. `npx hyperframes lint && npx hyperframes check`, snapshot, render with `--workers 4`.
Set `data-duration` in `index.html` to `SCENE.duration`.

## params.js
```js
window.SCENE = {
  duration: 20, seed: 11, font: "tech", tag: "OUR CALCULATION · …",
  camera: [{ at: 0, scale: 1, x: 0, y: 0 }, { at: 20, scale: 1.05, x: -20, y: 0 }],
  steps: [
    { write: "You paid ₹1,500", x: 230, y: 330, size: 120, color: "green", at: 3.2, dur: 1.9 },
    { underline: "last", color: "green" },
    { write: "Bank added ₹1,981", x: 230, y: 600, size: 120, color: "red", at: 5.8, dur: 2.7 },
    { circle: "last", color: "red", dur: 0.7 },
    { arrow: [700, 430, 880, 610], color: "red", bend: 0.18 },
    { erase: true, at: 9.75, dur: 1.4 },            // duster; optional region: [x, y, w, h]
  ],
};
```
- **write**: `x`,`y` = left end of the baseline (or `cx` to centre); `size` = capital height in px (auto-shrinks to fit
  before x = 1780, or `right`); `font`: `tech` (default, marker print), `readability`, `nixish`, `felix`, `allure`,
  `script`, `sans`; `track` spacing; `wobble` 0–1 (hand-made jitter); `speed` px/s (default 17 × size).
- **shapes**: `underline: [x1, x2, y]`, `strike`, `circle: [cx, cy, rx, ry]`, `arrow: [x1, y1, x2, y2]`, `box: [x, y, w, h]`,
  `tick: [x, y, s]`, `cross: [x, y, s]`, `bar: [x, base, w, h]` (hatched chart bar), `line: [x, y, x, y, …]`;
  `underline/circle/strike/box: "last"` wrap the previous item.
- **timing**: `at` (s); omitted = right after the previous step. `dur` fits a step to a VO phrase. Steps never overlap
  (one hand): an `at` earlier than the previous step's end waits for it (console warning).
- **colours**: `black`, `blue`, `red`, `green`, `orange`, `purple` or any CSS colour.
- In code: `const b = WB.board(stage, { seed }); b.write(…); b.circleLast(…); b.attach(tl);` (see `wb.js`).

## Fonts and licences
`wb-fonts.js` is generated by `node scripts/build_wb_fonts.mjs` from `hersheytext@2.0.0` (MIT; pinned devDependency):
EMS single-line fonts (SIL Open Font License 1.1, Evil Mad Scientist / Sheldon B. Michaels) and Hershey data (public
domain). `₹ × → ✓ …` are added in the same pen style by the build script. Curved accented glyphs (ß, ç) are skipped.

## Determinism and cost
Everything is `f(t)`: `render(t)` recomputes every stroke, the pen and the duster from the timeline time (onUpdate,
after all tweens), with seeded jitter. Stroke lengths and points are computed in JS, not by the DOM.
Render cost (1080p, `--workers 4`, cloud VM): 20 s scene in 68 s (≈3.4 s per output second).
